使用说明
1. 在 platform.deepseek.com 创建 API Key 并充值少量金额，填入上方保存。
2. 识别结果不对时点「改选母题」，你的纠正会直接教会本地网络，不花 token。
3. 组合题会同时给出多个母题；也可自己多选组合确认，下次相似题直接认识。
4. Key 与学习数据只保存在本机，不上传任何服务器；识别时题目仅发送给 DeepSeek 官方接口。
5. 若提示网络/跨域错误，请检查网络后重试。
