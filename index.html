DeepSeek 设置

Key 只存本机

阈值越高越谨慎（更多题交给 DeepSeek＋人工确认），越低越省 token。建议 0.85。

识别不准时的自救：① 点「改选母题」勾选正确答案（组合题多选），本地网络立即学会这类知识点→母题的映射，不花 token；② 新母题走「录入 → JSON 导入」，直接把母题 JSON 文件喂进来；③ 换手机前「导出学习数据」＋「导出题库 JSON」，新设备导入即恢复全部学习成果。

录入母题

直接导入母题 JSON 文件（数组，每条含 name / triggers / rules / sampleQuestion / solution / moveName / move 等字段，与你的母题库 JSON 结构一致）。同名母题自动跳过，导入后本地网络立即学习新母题。
选择母题 JSON 文件，或粘贴到下方
一条母题 = 一个原子模型（一个大招）。综合题靠识题时多选母题叠加覆盖。
搭桥逻辑：DeepSeek 只负责读题 → 输出知识点短语（提示词里不带母题目录，题目多长都只花这一小段 token）；知识点 → 母题的映射由本地神经网络完成，跟着你的每次确认/纠正学习，越用越准、越用越省。

输出格式必须保持 {"k":["知识点",...]}，否则解析会失败。想加学科约束（如「只输出高中数学考点」）可直接改文字。
